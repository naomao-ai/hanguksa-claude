RAG 데이터 분석 시스템 운영 매뉴얼

본 매뉴얼은 사내 폐쇄망(Offline-First) 환경에 구축된 RAG(Retrieval-Augmented Generation) 데이터 분석 시스템의 사용자와 관리자를 위한 가이드라인입니다. 데이터를 업로드하고, 에이전트의 분석 쿼리를 관리하며 시스템을 최적화하는 전 과정을 설명합니다.

1. 일반 사용자 가이드

1.1 엑셀 데이터 업로드 및 DRM 예외 처리

시스템에 정형 데이터를 추가하기 위해 엑셀 파일(.xlsx, .xls)을 업로드할 수 있습니다.

  • 스프레드시트 뷰 상단의 엑셀 업로드 버튼을 클릭하여 파일을 선택합니다.
주의: DRM 암호화 파일 감지
사내 보안(DRM)이 적용된 파일은 데이터 자동 추출이 차단됩니다. 경고 팝업이 발생할 경우 다음 중 하나의 방법으로 조치하세요:
  • 사내 복호화 툴을 이용해 DRM을 해제한 후 다시 업로드합니다.
  • RPA 분석(매크로) 기능을 사용하여 화면 상에서 텍스트를 자동 추출합니다.
  • 보안팀에 시스템 접근이 가능한 'DRM 예외 폴더' 설정을 요청합니다.

1.2 벡터 데이터 탐색기 활용

업로드 후 벡터화된 데이터가 LLM에 어떻게 색인되었는지 확인하고 검색할 수 있습니다.

  • 대시보드 우측 데이터 임베딩 현황 카드의 벡터 데이터 탐색기 버튼을 클릭합니다.
  • 검색창에 자연어로 키워드를 입력하여 시스템이 색인한 문단(Snippet)과 문서 출처, 유사도(Distance)를 실시간으로 확인할 수 있습니다.

2. 관리자(Admin) 운영 가이드

2.1 에이전트 분석 로그 모니터링 및 필터링

LLM 에이전트가 변환한 SQL 및 데이터 검색 쿼리의 이력을 조회합니다.

  • 상태 필터: 성공 / 실패 여부에 따라 쿼리를 필터링합니다.
  • 모델 필터: Llama-3, Mistral 등 쿼리를 생성한 LLM 종류별로 필터링합니다.
  • 시간 필터: 최근 1시간, 24시간 내 발생한 쿼리만 모아볼 수 있습니다.

2.2 쿼리 에디터 및 AI 진단 (수동 보정)

에이전트가 잘못된 쿼리를 생성하여 실패(Syntax Error 등)가 발생한 경우, 관리자가 이를 즉시 보정할 수 있습니다.

AI 제안 보기 기능
실패한 로그를 클릭하면 쿼리 에디터 팝업이 열립니다. 에디터 우측 상단의 AI 제안 보기를 클릭하면 인공지능이 쿼리 실패 원인(예: 오타, 존재하지 않는 테이블 참조 등)을 분석하여 올바른 쿼리를 추천합니다. 적용 버튼을 눌러 즉시 쿼리를 수정하고 재실행할 수 있습니다.

2.3 분석 성능 대시보드 및 리포트 내보내기

시스템의 쿼리 처리 효율을 시각적으로 확인하고 보고서를 생성합니다.

지표명 설명
평균 실행 시간 SQL 또는 벡터 검색 시 소요된 평균 응답 시간(ms)
평균 반환 행 수 성공한 쿼리가 반환한 평균 데이터 Row 개수
쿼리 성공률 전체 요청 쿼리 중 구문 오류 없이 실행에 성공한 비율
  • 차트 분석: SELECT, JOIN, AGG 등 쿼리 유형별 소요 시간을 막대그래프로 파악합니다.
  • 보고서 내보내기: 대시보드 우측 상단의 보고서 내보내기를 클릭하여 현재 성능 지표와 로그를 PDF/CSV 형식으로 다운로드(Export) 합니다.

2.4 시스템 설정 및 자동 최적화 모드

대시보드 상단의 관리자 설정(톱니바퀴)을 눌러 시스템의 백그라운드 동작을 제어합니다.

  • 로컬 모델 및 DB 경로 설정: 폐쇄망 내 위치한 GGUF 모델 파일과 Vector DB의 절대 경로를 매핑합니다.
  • 자동 최적화 모드 (Auto-Optimize):
    • 해당 기능을 켜두면, 벡터 데이터베이스의 인덱스 효율성이 80% 미만으로 떨어질 때 시스템이 백그라운드에서 자동으로 인덱스를 재구성(Reindex)합니다.
    • 데이터가 빈번하게 추가, 삭제, 업데이트되는 환경에서 검색 속도 저하를 방지하기 위한 필수 기능입니다.
